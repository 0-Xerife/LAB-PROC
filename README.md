# Laboratório de Processadores e Microcontroladores (LABPROC) 💻⚙️

## 🛠️ Tecnologias e Ferramentas (a princípio)
* **Hardware:** ESP32-C3 Super Mini (Arquitetura RISC-V 32-bit)
* **Linguagens:** C++ (Arduino Framework) e RISC-V Assembly
* **Simuladores:** CPulator (Simulação Bare-metal RISC-V)
* **Ambiente de Desenvolvimento:** VS Code
